## Description

UNBOUND Access helps people work through fictional paperwork one question at a time. Large controls and read-aloud support spoken or typed answers. Every answer needs confirmation. Shared applicant facts can be corrected together without changing someone else's details. Source-linked review and a readable PDF answer record keep the person in control. Nothing is automatically submitted.

The working path includes two authored practice forms, guided speech commands, required/conditional validation, correction history, in-tab recovery and PDF export with persistent save/open links. An actual typed browser run completed a form, rejected an out-of-range count, accepted zero income, revealed a conditional follow-up, corrected both linked home addresses while preserving the landlord address, and downloaded the reviewed two-page PDF. There are 86 passing automated checks. One tester reported basic phone sound, microphone and sample-PDF opening; full phone dictation and measured usability have not been established.

## Meta use

Built with Llama. An optional browser-local Meta Llama 3.2 1B Instruct GGUF runs real inference through wllama with no API key or paid fallback. Its roughly 808 MB download is opt-in, pinned, and removable. Compact structured proposals pass source/input checks and explicit human confirmation before saved state can change.

Preserved raw development receipts show the revised model handled three clear answers (three people, zero dollars, No), but guessed a number for uncertain input. A source guard now rejects such guesses; this is not counted as a model pass. The short-form extraction attempt failed required-flag validation. General extraction is experimental and unreliable, and CPU inference is slow. This is not an accuracy benchmark, GPU-performance claim or completed phone voice study.

A prior Meta Muse Glimmer 30B public-playground proposal is also preserved unchanged. It failed import; a separate reviewed derivative documents seven identifier fixes and one wording correction. Loading that captured example makes no new model call, and arbitrary pasted responses retain unverified manual provenance. Hosted NVIDIA/OpenRouter inference remains unconfigured. No unchanged Muse pass or live hosted API result is claimed.
