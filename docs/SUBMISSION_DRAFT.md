## Description

UNBOUND Access helps people work through fictional paperwork one question at a time. Large controls and read-aloud prompts support spoken or typed answers. Every answer is proposed for confirmation, and users can correct shared facts without changing another person's details. Source-linked review and a readable PDF answer record keep the person in control. Nothing is submitted automatically.

## What works today

Two authored practice forms, guided speech controls, spoken clarification choices, review/download commands, explicit confirmation, required and conditional validation, isolated shared-fact corrections, in-tab recovery and readable PDF export with direct save/open links. A manual route copies a Meta extraction prompt and checks pasted question proposals before approval. It retains manual provenance and does not verify model/provider identity. The suite has 79 passing tests. Boyd reported that phone audio, microphone and saving/opening the sample PDF worked; these are basic device checks, not a measured user study.

## Meta contribution

Meta Muse Glimmer 30B in NVIDIA's public playground produced a nine-question proposal from an original fictional workshop form. The original output failed import: seven fact keys were blank and name help added an unsupported legal-name qualifier. The preserved DOM output, boolean reconstruction, separate reviewed derivative and exact eight-edit audit are included in the source. The corrected proposal passes the app's source validator and drives the demonstration's conditional question, companion bound and linked-address correction. It is a captured, reviewed proposal; loading it makes no new model call. The app retains manual provenance and cannot verify arbitrary pasted responses' model/provider identity.

A server adapter for NVIDIA's free endpoint is implemented with a free-availability guard, fixed endpoint/model and no paid fallback. No API key is configured; live server extraction and AI answer mapping remain untested. No unchanged model pass, live API benchmark or timed usability result is claimed.
